# 流量文章写作（AI 模型新闻/评测类）

为 AI 模型发布/评测写流量文章，投放 CSDN、知乎、掘金、公众号等平台。用户的业务是 AI API 网关（智体工坊），这类文章是获客内容。

## When to Use

- 「写一篇文章 / 去写篇稿子，我要放 CSDN 和各种社交平台」
- 「要流量最大」的模型发布 / 横评 / 对比解读
- 文章需带 benchmark 数据或价格对比

## 核心工作流

1. **多源搜索**：官方 API 文档（定价页）+ 至少 3 个独立媒体（IT之家/快科技/澎湃/新浪/36氪 等）交叉验证
2. **数字必须从官方原表核实，不抄媒体转述**：
   - 官方定价页直接抓（`webReader` 读 api-docs.deepseek.com 等）
   - 官方对比表若只有图片（媒体文章里的截图），**下载图片 + 视觉模型逐格读表**（`analyze_image`，提示词要求逐行输出所有基准×模型×分数）
   - 用官方表修正媒体说法——媒体标题会夸大/误植（见 Pitfall 1）
3. **给读者"到底什么水平"的定位**：不要只写"有来有回/大幅提升"这种定性话。要给对比表（自家系列 + 顶级竞品 + 预览版），明确"同档/超越/落后"每项结论
4. **必须配图**：官方对比表截图（上传图床）或自绘对比图，放文章中部
5. **结构模板**：爆点标题 → 发生了什么 → 最炸数字 → 对比（自家 + 竞品）→ 规格表 → 价格 → 对开发者意味着什么 → 怎么用 → 数据来源
6. **写完发 Wiki 供审阅**（路径 `agents/content-writer/articles/...`，见 `wiki-page-authoring` skill），发链接给用户

## 用户偏好（已被纠正过）

- **「到底什么水平」是读者第一问题**——用户原话：「那到底处于什么水平呢」「这些读者最关心的吗」。文章必须有数据化定位，不能停留在定性吹
- **必须有图**——用户原话：「没有图片吗」。无图 = 不完整
- 技术博客**叙述式**，不写成配置文档
- **CSDN 不营销链接、不喊口号**（会被判营销降权）
- 每个数字标来源；无实测数据别断言效果

## Pitfalls

### Pitfall 1: 媒体转述的 benchmark 数字会失真

实例（2026-08-13 DeepSeek V4 Pro 正式版）：
- 媒体普遍写「DeepSWE 从 7.3 暴涨到 62.7，接近 9 倍」——官方原表实际是**预览版 12.8 → 62.7（约 5 倍）**，7.3 是 Flash 预览版的分数，媒体混了
- 媒体写「超越 Opus 4.8」——官方原表是**互有胜负**：10 项里 4 项超（DeepSWE 62.7 vs 58.0、Terminal Bench、CyberGym、Automation-Bench）、3 项平、3 项落后（HLE、NL2Repo、DSBench-Hard 落后 6-8 分）

教训：**任何 benchmark 数字，先找官方原表（含图片），别信媒体标题**。图片用视觉模型读，逐格提取。

### Pitfall 2: 拿不到官方精确分数时，只写定性结论，不编数

如果官方对比表是图片且读不出来/没有公开——写「超越 X / 与 Y 相当」这类媒体一致的定性结论即可，**绝不自己编具体分数**（用户红线：「你确认？」/「为什么瞎猜」）。

### Pitfall 3: 定价钩子要有原文出处

「近期涨价」这类紧迫感钩子可以用，但必须是官方定价页原文（如「计划近期整体上调…预计涨幅较大」），并注明出处。

## 平台标题分化策略

| 平台 | 打法 |
|------|------|
| CSDN | 原标题即可，型号全称（如 DeepSeek-V4-Pro-0813）进标题吃 SEO |
| 知乎 | 提问体 + 观点对立引评论 |
| 掘金 | 干货体：零迁移/上手/选型 |
| 公众号 | 情绪标题（深夜突袭/不声不响放大招） |
| V2EX/即刻 | 短评 + 原文链接，别全文搬运 |
